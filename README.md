# Local AI Assistant

A local AI assistant built using Ollama and Python.

## Features

- Streaming responses
- Multi-session chat
- Persistent conversation memory
- AI-generated chat titles
- Multiple assistant personas
    - DSA Interviewer
    - AI Mentor
    - Resume Reviewer
    - Travel Planner

## Tech Stack

- Python
- Ollama
- Qwen2
- JSON
